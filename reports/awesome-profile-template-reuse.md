## 2. Reused Templates & Synthesis Breakdown

### A. Template 1: `templates/05-dashboard/analytics-grid`
- **Original Asset**: `assets/dashboard/analytics-grid.svg` (`viewBox="0 0 1200 420"`)
- **Visual Concepts Reused**:
  - Four-tile KPI card grid structure (`width="258" height="130"`, rounded corner radiuses `rx="12"`).
  - Hand-drawn sparkline polyline geometry with vertical alpha-gradient area fills.
  - Multi-bar animated streak meter with SMIL pulsing latest-day bar (`<animate attributeName="height" ... repeatCount="indefinite"/>`).
  - Top live telemetry status strip with SMIL pulsing live indicator dot (`values="0.4;1;0.4"`).
  - 90-day continuous velocity area polyline chart with dual-concentric radar-blip live pulsing circles (`r="4;7;4"` and `r="10;18;10"` with opacity decay).
- **Modifications / Recreation**:
  - Adapted color scheme to Subhajit Kar's Midnight Glass design system (`#0d0e16` background, `#22d3ee` cyan, `#a78bfa` violet, `#f472b6` pink, `#34d399` emerald).
  - Populated strictly with verified portfolio and GitHub metrics (`300K+ Identities / Mo`, `80–90% Defect Reduction`, `250+ ServiceNow RITMs`, `56 Verified Technologies`).
  - Adapted the 7-day weekday cadence dots into a 7-domain enterprise ecosystem indicator (`IAM`, `IGA`, `SEC`, `CLOUD`, `AI`, `DEV`, `OPS`).
