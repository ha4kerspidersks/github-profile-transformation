# Reference Design Process Analysis

## 1. Overview
The reference transformation pipeline pioneered by the reference profile combines prompt-engineered vector generation, micro-frame video synthesis, and declarative SVG standards (SMIL + CSS3) to bypass GitHub Markdown rendering restrictions while achieving interactive portfolio aesthetics.

## 2. The 6-Stage Process Lifecycle
```
[Stage 1: Media Capture] 
   └── Short 2-second motion clip (or AI-generated dynamic character)
[Stage 2: Character Art Generation]
   └── High-fidelity anime-style avatar & full-body pointing pose
[Stage 3: SVG Component Decomposition]
   ├── hero.svg (Video Viewfinder HUD + Typography + SMIL switcher)
   ├── about-life.svg (Dual browser/carousel capability cards)
   ├── stack.svg (Orbital physics + 56-tech chip matrix)
   ├── id-dashboard.svg (Pendulum lanyard + telemetry metrics)
   └── connect.svg (Pointing character + interactive links)
[Stage 4: Markdown Composition & Integration]
   └── README.md layout tables, responsive constraints, cache busting (?v=1)
[Stage 5: Daily 3D City Automation]
   └── GitHub Actions cron workflow generating isometric contribution geometry
[Stage 6: Multi-Stage QA & Visual Regression]
   └── Playwright viewport rendering, DOM validation, accessibility audit
```

## 3. GitHub Runtime Isolation & Constraints
1. **JavaScript Stripping**: GitHub sanitizer removes all `<script>` tags, inline event listeners (`onclick`), and foreign iframes.
2. **CORS / Asset Proxies**: GitHub caches all external images through `camo.githubusercontent.com`.
3. **Cross-Origin Font Blocking**: External `@import` or `<link>` font stylesheets are blocked by Content Security Policy.
4. **SMIL & CSS Survival**: Declarative SMIL tags (`<set>`, `<animate>`, `<animateTransform>`, `<animateMotion>`) and standard SVG CSS keyframes remain fully functional in GitHub's SVG renderer.

- **Enterprise IAM Theme**: Replaced generic personal lifestyle cards with enterprise-grade Identity Governance, SailPoint IIQ/ISC workflows, and Cloud Security architecture.
