### Key Limitations & Deficiencies (Targeted for V2 Overhaul)
1. **Lack of Visual Impact**:
   - The hero banner was a flat SVG with minimal depth, no integrated portrait, and no cinematic motion effects.
   - Compared to the reference (`hero.svg`), it lacked the high-end glassmorphism, terminal HUD telemetry, and glowing cyber perimeter.
2. **Fragmented Technology Presentation**:
   - The 56 technology cards were listed as 56 separate HTML anchor tags `<a href="..."><img ... /></a>`. While functional, this creates a staggered block of badges rather than a **single, unified, jaw-dropping technology constellation wall** (`stack.svg`).
   - The prompt explicitly mandates: *"Create ## Tech Stack then ONE unified visual technology wall. NO category headings. NO category descriptions... It should look like a premium technology constellation."*
3. **Missing Interactive ID / Holographic Dashboard**:
   - The reference profile showcases an interactive, swinging holographic developer ID badge next to an enterprise statistics dashboard (`id-dashboard.svg`).
   - Subhajit's profile had a simple horizontal metrics banner that did not match the sophistication of an enterprise security clearance dashboard.
4. **No Automated 3D Contribution City**:
   - The reference repo utilizes `yoshi389111/github-profile-3d-contrib` to render a 3D isometric contribution skyline (`profile-night-view.svg`).
   - Subhajit's profile repo lacked the automated `.github/workflows/profile-3d.yml` workflow to generate this skyline dynamically.
5. **Connect Section Simplicity**:
   - Connect links were plain badges rather than a futuristic cyber terminal connect board (`connect.svg`) with verified social networks.
6. **Avatar Mismatch**:
   - The actual GitHub account avatar is an older default, while the portfolio has an executive cyber risk leader portrait.
